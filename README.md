# SOS Bot

Telegram-бот для швидкої взаємодопомоги поруч. Основні сценарії:

- **🆘 SOS** — створює кейс, надсилає геолокацію або текстовий орієнтир і розсилає запит READY-хелперам поруч.
- **🤝 ГОТОВИЙ** — хелпер надсилає локацію, вмикає готовність на заданий час і отримує SOS-повідомлення.

> Якщо є реальна загроза життю — телефонуйте 102/103/112.

## Запуск

1. Створіть Telegram-бота та отримайте токен.
2. Встановіть залежності:

```bash
pip install -r requirements.txt
```

3. Запустіть:

```bash
BOT_TOKEN=... python bot.py
```

За замовчуванням дані зберігаються у `bot.db`. Можна змінити шлях через `BOT_DB_PATH`.
